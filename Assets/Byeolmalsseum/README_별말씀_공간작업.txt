별말씀 · 단어 공간 작업 도구 사용법
====================================

[처음 한 번]
1. 받은 Assets 폴더를 프로젝트 폴더에 덮어쓰기
2. 메뉴 Tools > 별말씀 > 공간 씬 만들기 · 열기 > (내 단어)
   → Assets/Words/(단어)/(단어)_공간.unity 가 생기고 열림
   → 이미 있으면 절대 덮어쓰지 않고 그냥 열어줌

[씬 구성]
[별말씀] (단어)               ← 선택하면 인스펙터에 도구 버튼들
 ├ 글자 (자모를 옮겨서 공간 만들기)
 │   └ 1 길                    ← 음절 그룹 (옮기면 안의 자모가 한꺼번에)
 │       ├ 초성 ㄱ             ← 자모 하나 = 움직이는 단위 (옮기고 늘려서 기둥·벽 등으로)
 │       ├ 중성 ㅣ
 │       └ 종성 ㄹ
 ├ 공간 (소품·조명 등 여기에)  ← 자유롭게 작업
 ├ 체험 카메라 경로            ← 자식 = 경로점. 선택하면 Scene 뷰에서 바로 끌어 옮김
 ├ 체험 카메라
 └ 작업용 카메라

[작업 규칙]
- 초성/중성/종성(자모)을 옮기고 / 돌리고 / 크기(Scale)를 바꿔서 공간을 만든다.
  지금 보이는 상태 = 체험의 최종 상태. 쌍자음·겹받침·이중모음(ㄲ, ㄺ, ㅘ)도 한 덩어리.
- 모든 자모가 공간 어딘가에 들어가야 함 (인스펙터 진행 막대로 확인, '안 옮긴 자모 선택하기' 버튼)
  자모 개수: 길차다 7 / 논틀밭틀 12 / 살천스럽다 13 / 퍼르퍼르 8
- 자모를 복제하거나 지우지 않기
- 색·재질: 자모의 자식 'Visual'의 머티리얼을 바꾸면 됨
  (Assets/Words/(단어)/Materials 에 초성·중성·종성 기본 머티리얼)
- 씬에서 클릭하면 자모가 선택됨. 음절 그룹은 하이어라키에서 고르거나 자모 인스펙터의 버튼
- 단어 이름, 자모 밑 'Visual' 구조는 바꾸지 않기

[플레이해서 확인]
- 글자가 카메라 앞에 나타남 → 4초 → 모든 자모가 한꺼번에 공간 자리로 날아감 → 카메라가 경로를 반복 이동
- 마우스 위치로 시선 이동 / 오른쪽 아래 [체험 종료]
- Tab: 작업용 카메라 ↔ 체험 카메라
  (작업용: 우클릭 드래그 둘러보기, WASD 이동, Q/E 아래·위, Shift 빠르게)
- 연출 기다리기 귀찮으면 인스펙터 '테스트용 > skipIntro' 체크
- 시간 조절: glyphHoldSeconds(글자 보여주는 시간), flySeconds(날아가는 시간)

[백업 — 공간 날아감 방지]
- Ctrl+S 할 때마다 Backups/Auto 에 자동 백업 (최근 20개)
- 인스펙터 [지금 배치 저장 (백업)] = 배치 백업 + 씬 파일 통째 복사본
- 되돌리기: 백업 파일을 인스펙터 칸에 끌어 넣고 [이 백업 불러오기] (Ctrl+Z 가능)

[합칠 때]
- Assets/Words/(내 단어) 폴더 통째로 보내기
- Assets/Byeolmalsseum/Core 폴더는 수정하지 않기 (공용 코드)
- 체험 종료 신호: WordSpace.ExperienceFinished (코드) 또는 인스펙터 onExperienceFinished (이벤트)
  끝낸 단어는 WordSpace.LastFinishedWord 로 다음 씬에서 읽을 수 있음
  인스펙터 nextSceneName 에 씬 이름을 적으면 종료 후 그 씬으로 바로 이동
- 작업용 카메라(Tab)는 에디터에서만 동작. 전시용 빌드에서는 체험 카메라만 쓰임 (지워도 됨)
